# HA Universal Voice icon

Generated with the built-in image generation tool, then resized to 256 and 512 pixels while preserving transparency. The bundled assets are `custom_components/universal_stt/brand/icon.png` and `icon@2x.png`.

The concept was generated before the final product name was chosen. The artwork contains no text.

## Generation prompt

Use case: logo-brand. Create one polished square icon for Universal Voice, a Home Assistant integration for both speech recognition and speech synthesis. A single bold geometric mark combining a speech bubble with three rounded audio waveform bars, suggesting listening and speaking. Teal and deep blue, crisp flat shapes, strong silhouette readable at 32px, centered with modest padding. Transparent background. No text, no letters, no watermark, no mockup, no gradients or shadows. Deliver a single icon, not a sheet of alternatives.
