# Naming

Preserve the integration domain and package name `universal_stt`. The user-facing
product name is HA Universal Voice. Follow the existing Python and Home Assistant
names around each change; no custom symbol prefix or ticket prefix is configured.

Use `tests/test_*.py` for tests and the existing naming patterns for configuration
keys and provider identifiers. Consult [the glossary](../../work/GLOSSARY.md)
for existing product terminology.
